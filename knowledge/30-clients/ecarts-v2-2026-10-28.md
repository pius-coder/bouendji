# Ecarts v2 vs code (lecture de code, aucune execution)

Reponse a : "les flux de la v2 n'ont pas ete respectes". Decisions D132-D134.

## Dashboard (apps/dashboard)
- Navigation (components/shell/nav-model.ts) : 4 sections en barre + 3 derriere Plus, **11 entrees**
  (Abonnes, Appareils, Commandes, Secours, Forfaits, Application, Assistant marque, Versements,
  Commissions, Equipe, Journal...). Le v2 prevoit 5 ecrans a onglets + tiroirs. Ecart : les onglets
  sont des **pages separees** (19 page.tsx), pas des onglets.
- Meme sidebar pour tous : filtrage par permission seulement ; le v2 veut un parcours par role
  (Reseau seul = Ce soir / Jour / Historique / Compte).
- Absents : Plateforme > Equipe plateforme, Demandes de build (UI), Reseau > Ce soir/Historique,
  Communaute > Reglages WhatsApp, presence, SSE. Voir efonte-admin-artifact.
- Tiroirs (Abonne, Appareil, Commande, Forfait, Versement) : a verifier page par page (non verifie).

## Forfaits
- API : familles limited, limited_night, custom (dmin.ts, catalog.ts, me.ts).
  **Aucune famille illimitee** : D115 l'avait supprimee. A reintroduire (D132).
- Android ui/screens/Plans.kt (~l.170-245) : CustomBuilder = 2 sliders (Go, validite) avec
  	erms.priceXaf(gb, days) ; plage de nuit en Segmented. L'illimite n'a pas de carte.
- Prix : l'illimite doit avoir son prix propre par forfait + controle du plancher (pricing.ts).
