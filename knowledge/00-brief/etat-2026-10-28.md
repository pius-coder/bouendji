## Dev local — pile complète sur PGlite (2026-10-28)

Aucun Postgres local, aucun Docker/WSL sur cette machine : la pile tourne sur
PGlite, la base de développement étant le dossier `apps/api/.pgdata` (ignoré
depuis le 2026-10-28).

**Piège vérifié** : `DATABASE_URL=./.pgdata bun dev` **ne suffit pas**. Turbo 2
filtre l'environnement des tâches ; la variable est supprimée, puis
`tsx --env-file=.env` réinjecte `DATABASE_URL=postgres://…localhost:5432` et
l'API meurt en `ECONNREFUSED 127.0.0.1:5432`. Correctif : `passThroughEnv:
["DATABASE_URL"]` sur la tâche `dev` de `turbo.json` (vérifié : sans la clé,
échec ; avec, `Server listening at http://127.0.0.1:8080`).

Démarrage :

```bash
cd apps/api && DATABASE_URL=./.pgdata bun run seed   # idempotent, une fois
DATABASE_URL=./.pgdata bun dev                        # depuis la racine
```

Vérifié le 2026-10-28 :

- dashboard `http://localhost:3000/login` → **200** en 4,2 s ;
- API `http://localhost:8080` → écoute, `x-access-key` exigée ;
