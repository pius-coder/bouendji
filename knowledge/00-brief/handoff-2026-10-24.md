- Variables GitHub : `R2_ACCOUNT_ID`, `R2_BUCKET=vpn-apps`.
- Secrets GitHub de signature : `ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`,
  `ANDROID_KEY_PASSWORD`, `ANDROID_KEY_ALIAS` (= `bouendji`). Keystore RSA 4096,

  `app-release-unsigned.apk`, 81 499 772 octets.
